# Mamad Burger

Source files extracted from the original `olampiad.zip` provided by the project owner. The original source layout is preserved, including nested directories.

## Upload using the GitHub website
1. Create a **private** repository named `mamad-burger`.
2. Extract this ZIP on your computer.
3. In the repository choose **Add file → Upload files**, then drag the **contents** of the extracted folder (not the ZIP) into the upload area.
4. Choose **Commit changes**. If GitHub rejects a batch, split files into smaller batches and keep the folder paths.

## Notes
- `node_modules`, caches and generated build folders were excluded. Install dependencies based on each project's package manifests.
- Review any included SQL exports for real user information before making the repository public.
- Do not publish credentials or personal data.
